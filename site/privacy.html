Understudy recorder — privacy

Applies to the Understudy recorder browser extension. Last updated 20 November 2026.

In short: nothing the extension records leaves your computer. It talks only to the Understudy program running on your own machine, at 127.0.0.1. There's no Understudy server, no account, no analytics, and no tracking.

What it records, and when

Only while you're recording — after you click Record from this page, on that tab, until you click Stop:

  • Your clicks, key presses and selections, and the page address each happens on.
  • What you type into fields. Passwords are never recorded: a password field is stored as a name like SECRET.password, and you supply the value when replaying.
  • The name and type of each element you interact with (e.g. the button "Log in"), so the step can be replayed.

Outside a recording, it does nothing.

Your sign-in

When you start recording, the extension copies that site's cookies and local storage, so a replay can start signed in the way you were. They're saved as a file on your computer that only your user account can read. If the flow turns out not to need them, Understudy deletes the copy when you save the flow.

Where it all goes

Each recorded action is sent to the understudy program on your machine (127.0.0.1), using a one-time code that web pages can't read. The program saves the recording to a folder on your computer. If you then save it as a flow, it goes into the MongoDB database you configured — your own Atlas cluster or your own server. If you also configured an embedding model (Voyage, by default) so goals can be matched by meaning, Understudy sends it only the short texts it searches by — a flow's name and description, facts and lessons, the goals you ask for — never the recorded steps, anything typed, or your cookies. The extension's authors never receive any of it.

Permissions, and why

  • Access to a site — asked for one site at a time, when you first record there, so the recorder can run on that page.
  • Cookies — to copy your sign-in for replay, as above.
  • Scripting — to run the recorder on the tab you're recording.
  • Navigation — to keep recording when a click opens a new page.
  • Storage — to remember which tab is being recorded, and your port setting.

Questions

Open an issue on GitHub. The extension is open source; you can read exactly what it does in the extension folder.
